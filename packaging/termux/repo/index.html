freebuff-native

Native Freebuff CLI for Termux: the upstream binary runs on the Android kernel through Termux's glibc loader, with no proot and no ptrace.

Install

curl -fsSL https://mbanucu.github.io/freebuff-native-termux/install.sh | bash
pkg install freebuff-native
freebuff-native --download
freebuff

The install script downloads freebuff-repo_all.deb, installs it, and runs pkg update. If you prefer to inspect it first, download that file and run pkg install ./freebuff-repo_all.deb.

What the package does

freebuff-native installs the glibc runtime, fetches the current official Freebuff release, verifies its published sha256, and writes the launcher. The 136 MB binary is not in the package; it is fetched on first use from GitHub. --from DIR remains the offline path.
